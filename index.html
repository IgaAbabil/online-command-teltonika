    Sumber data: Teltonika Wiki, halaman Data Sending Parameters ID dan Parameter list untuk FMB130 (firmware FMB.Ver.03.29.00 ke atas). Sebagian besar ID berlaku juga untuk seri FMB lain, tapi tetap cek dokumentasi model perangkatmu. I/O element dibaca dengan readio <ID>. Parameter dibaca dengan getparam <ID> dan diubah dengan setparam <ID>:<nilai>. Lewat SMS tanpa login dan password, awali perintah dengan dua spasi. Perubahan parameter langsung berlaku di perangkat, jadi cek ulang nilai sebelum mengirim.
